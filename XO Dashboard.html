    EXHAUSTIVE GAME TREE

    O maximizes its worst-case outcome.

    For each empty square, the computer places a temporary O, explores every legal continuation, and assumes X chooses the strongest reply. Scores are from O’s perspective.

    V(s) = max V(child) for O · min V(child) for X

    Terminal O win: 100 − occupied squares. X win: occupied squares − 100. Draw: 0. This prefers an earlier win and delays a forced loss. Equal scores prefer the center, then corners, then edges.

    Start a game on the Play dashboard to inspect a real decision.

    Game state and physical state

    An X click creates a pending O decision. The square is reserved while the placement runs. O becomes committed only when simulation finishes or the controller reports one completed pick-and-place cycle. A stopped or failed cycle locks the game for inspection.

    Motion settings

    Base settings are read from your controller on connection. Defaults shown while disconnected are not measured values. Changing base trim or speed invalidates its angle/time calibration and home reference.
